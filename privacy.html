Privacy Policy

Saint Mary Titlebot

Saint Mary Titlebot is a personal automation tool used by the owner to manage YouTube live broadcasts for the Saint Mary and Archangel Michael Coptic Orthodox Church YouTube channel.

Google user data

The application uses the YouTube Data API with the https://www.googleapis.com/auth/youtube.force-ssl scope. It accesses only the owner's YouTube account to:

  • Create, list, and update live broadcasts and titles
  • Bind broadcasts to an existing live stream
  • Transition broadcasts between lifecycle states

Data collection and use

This application does not collect personal data from other users. It does not sell, advertise with, or share Google user data with third parties. YouTube data is used only to perform the broadcast-management functions described above.

Data storage and security

OAuth credentials and tokens are stored locally on the owner's computer. They are not uploaded to or stored by any external service operated by this application. The application does not maintain a separate database of YouTube user data.

Data retention and deletion

The owner may delete the locally stored OAuth token at any time by removing the application's token file. Access can also be revoked from the Google Account security settings.

Third-party services

The application communicates with Google APIs to manage YouTube broadcasts. Google's handling of data is governed by Google's Privacy Policy.

Contact

Questions about this application can be directed to the support email listed in the Google Cloud OAuth consent-screen configuration.
